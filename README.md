# Number Guessing Game

Guess a randomly chosen whole number from 1 to 100. The game tells you whether each guess is too high or too low and reports how many valid guesses you took to find the number.

## Run the game

Use Python 3. The game uses only the standard library.

```sh
python3 number_guessing_game.py
```

Enter a whole number from 1 to 100. Blank input, non-integer input, and numbers outside the range leave the attempt count unchanged. Type `quit` to reveal the secret number and exit. Ending input or pressing `Ctrl+C` also exits cleanly.
